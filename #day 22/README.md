# 🧱 Stack Visualization Project

## 📋 Overview
This project is a **Stack Visualization Tool** built using **HTML, CSS, and JavaScript**.  
It helps users understand how the **Stack Data Structure** works internally — showing real-time push, pop, and peek operations visually.  

The goal of this project is to make learning stacks easier and more interactive by demonstrating element flow, stack overflow/underflow conditions, and top pointer updates dynamically.

---

## ⚙️ Features
✅ Interactive stack visualization (push, pop, peek)  
✅ Real-time updates shown with animations  
✅ Stack overflow and underflow condition alerts  
✅ Displays top element dynamically  
✅ Clean and simple user interface  

---

## 🧩 Technologies Used
- **HTML5** → To create the structure and elements of the stack visualization  
- **CSS3** → For styling, layout, and animation effects  
- **JavaScript (ES6)** → For stack logic and DOM manipulation

## 🚀 How It Works
1. The stack is implemented as an **array** in JavaScript.  
2. When the user clicks **Push**, a new element is added on top visually and in the array.  
3. Clicking **Pop** removes the top element both visually and logically.  
4. **Peek** shows the current top element without removing it.  
5. Overflow and underflow conditions are handled with alerts/messages.

---

## 🔍 Example Operations
- **Push(10)** → Adds 10 at the top of the stack  
- **Push(20)** → Adds 20 above 10  
- **Peek()** → Shows “Top Element: 20”  
- **Pop()** → Removes 20  
- **Pop()** → Removes 10 (Stack empty message shown next)
