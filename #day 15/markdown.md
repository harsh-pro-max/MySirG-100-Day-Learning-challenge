# Markdown Tutorial

### Introduction
Markdown is a lightweight markup language that uses simple, plain-text formating to create structured documents that can be easily converted to HTML.

created by John Gruber in 2004, its design goal is to be human-readable and writable, making it easy to add formating like headings, lists, and bold text using basic symbols.

Markdown is widely used for creating teachnical documenation, web content, readme files, and content for platforms like GitHub, Azure DeveOps, and onine forums.

### How to create and preview Markdown file?
- create a new file and save it with a .md extension
- Open file in VS Code
- Press Ctrl+K V(Window/Linux),Press Cmd+K V (macOS)
